### 복습: Agent란?
- LLM과 Agent간의 차이 : Agent는 Action(LLM이 Tool을 사용함)을 한다.
- AX(AI Transformation)가 유행하고 있다.

### 1주차: Tool의 구현
- Tool은 함수 형태로 구현한다.
- @tool annotation을 통해 Tool임을 나타낸다.
    - Tool name
    - 설명
        - description 파라미터 :  이미 구현된 함수를 tool로 제작할 때 사용
        - Docstring(주석)
    - 이미 구현된 함수는 @tool annotation을 붙히기만 하면 되긴 하는데 설명이 필요함!
- 프로그래밍 하는 방식의 차이
    - 기존 : 구현한 함수(클래스)를 main에서 조합해서 순서대로 실행
    - 현재 : main에서 조합하는 행위를 LLM이 담당, 즉 사람대신 함수를 실행함.

### 2주차: 구조화된 출력
- Type(Class)을 직접 만들어서 데이터를 규정해보자!
- @dataclass annotation으로 LangChain에서 구조화하는 것도 있긴 하나, Class(Pydantic)을 주로 사용함.
- description 또는 docstring에서 파싱될 내용들을 잘 조절할 수 있으니 잘 해봐라.
