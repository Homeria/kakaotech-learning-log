### MCP & Tool Call
- 규약(Protocol) : 서로 대화나 정보를 주고받기 위한 규칙
    - 예시: MCP(Model Context Protocol), HTTP(HyperText Trasnsfer Porotcol), TCP/IP
- MCP
    - AI 모델과 사용자 사이에 규약을 통해 통신을 하겠다!
    - Tool call을 구현하겠다, 로컬이 아닌 MCP 서버(Server)에서!
    - 원래는 [Local - MCP Server - LLM]의 구조로 Tool을 사용했다고 생각하면 됨. 그래서 Tool Call 그림과 비슷함.
    - Tool : MCP 서버에 구현되어 있는 툴.
    - LLM을 위한 전용 API 서버라고 생각하면 가장 이해하기 쉬움
    - 여태까지 구현한 도구들이 바로 이 MCP 서버에 장착될 '알맹이(핵심 기능)'들
    - 사람들이 많이 쓰는 툴(예시: 지메일, 구글 캘린더 등 상용 프로그램)들을 서버로 만들고 가지각색의 tool로 구성해서 LLM이 쓸 수 있도록 한다?
    - MCP의 존재 이유가 "하네스 애매하게 할 바에 건들지 말고 LLM이 알아서 사용할 수 있게(결정권을 LLM에게) 해라~"라는 의미로 읽힐 수 있다는 Coach님의 의견.
