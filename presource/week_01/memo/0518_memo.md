
### functions
- strip() : 문자열의 양 옆 공백 제거
    - rstrip() : 문자열의 오른쪽 옆 공백 제거
    - lstrip() : 문자열의 왼쪽 옆 공백 제거
- split(기준 문자열) : 단어의 쪼개기
    - ex : "hello world".split() -> ["hello", "world"]
- append(데이터) : 리스트 맨 뒤에 데이터 추가
- get() : 딕셔너리에서 키가 없어도 에러 없이 "없음"을 반환
- list.copy() : 리스트를 "복사"하기 위해 사용 (리스트는 기본이 참조이기 때문.)

### Type Casting
- data_type(data) : data를 data_type으로 변환
    - ex: str -> int => int(str)
    - ex: int -> str => str(int)

### for - enumerate
- enumerate(list) : index와 리스트 요소를 한꺼번에 다룰 때 사용
    - ex : for i, e in enumerate(list):

### List Comprehension
- [target for target in list if condition] : for 한 줄로 리스트 구성. Filtering, Type Casting 등을 할 수 있음
    - ex : [e for e in list if condition]
    - ex : [str(e) for e in list]

### Early Return
- 여러 체크가 필요한 로직에 대해서 만족하지 않는 것을 먼저 찾는 것
- ex : 로그인, 상품 정보, 수량, 잔액을 모두 충족해야 할 떄
    - 1. 로그인을 하지 않는다면 -> 오류 반환
    - 2. 상품 정보가 없다면 -> 오류 반환
    - 3. 수량이 없다면 -> 오류 반환
    - 4. 잔액이 부족하다면 -> 오류 반환
    - 5. 모두 통과했으므로 정상적인 값 반환
- Nested if 문을 유지보수가 쉽도록 개선할 수 있음

### 가변 인자 (args, *kwargs)
- 함수의 인자 개수가 정해지지 않았을 때 사용
- *args (가변 위치 인자)
    - "Arg"uments (인자들)
    - 값만 쉼표로 나열하여 전달
        - ex: func("사과", "바나나")
    - 함수 내부에서는 튜플로 묶임
    - 개수가 정해지지 않은 여러 개의 단순한 데이터를 한 번에 받을 때
- ** kwargs (가변 키워드 인자)
    - "K"eyword "Arg"uments (키워드 인자들)
    - 이름=값 형태로 지정하여 전달
        - ex: func(model="gpt", temp=0.7)
    - 함수 내부에서는 딕셔너리로 묶임
    - 개수가 정해지지 않은 추가 옵션/설정값을 유연하게 받을 때
- 일반 인자 -> *args -> **kwargs 순서로 사용
    - ex: def func(name, *args, **kwargs)

### Data Class
- Magic Method : 개발자가 직접 함수를 호출하지 않아도 특정 상황에서 자동으로 호출
    - __init__ : 객체 초기화 : 객체 생성 시 필요한 초기 데이터(속성) 설정
    - __repr__ : 디버깅용 출력 : 개발자가 객체 상태를 파악하기 쉽게 출력
    - __eq__ : 동등 비교 : 객체 내부의 값을 기준으로 같은지 판단
    - __str__ : 사용자용 출력 : 사용자가 보기 좋은 문자열
- @dataclass 방식 : __init__, __repr__, __eq__ 자동 생성

### 2개 이상의 Parent Class가 존재할 때
- MRO() : Method Resolution Order
    - 상속받은 부모 class의 왼쪽부터 차례로 상속받게 되어 우선순위가 부여됨
- super()를 통한 부모 클래스의 함수 실행
    - super() : MRO 순서로 실행
    - super(시작클래스, self) : 시작클래스의 다음 순서에 있는 클래스의 메서드를 찾아 실행

### Capsulation
- 데이터(상태)와 그 데이터를 다루는 기능(메서드)을 하나로 묶음
- 외부에서 내부의 데이터를 함부로 들여다보거나 수정하지 못하게 막음
    - _name : "직접 접근 금지" 약속
        - ex : _balance
    - @property : 안전하게 읽기만 허용 (검증된 통로를 만듦)
